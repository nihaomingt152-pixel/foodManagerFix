# 🥗 膳康管家 — 个性化膳食图像识别与营养智能管理系统

> **4C 中国大学生计算机设计大赛参赛作品 | AI + 智能医疗健康方向**

## 📖 项目简介

膳康管家是一款基于深度学习的智能膳食管理应用。用户通过拍照上传食物图片，系统自动识别食物种类并计算营养成分，提供每日营养摄入统计、个性化饮食建议、AI 营养医师咨询等功能。系统采用 **YOLOv11** 进行食物目标检测，支持 **64 类** 常见中式菜肴和水果的识别，并集成本地大模型（Ollama + Qwen2.5）提供专业营养咨询。

## ✨ 核心功能

| 模块 | 功能说明 |
|------|---------|
| 📸 **食物识别** | 上传食物图片 → YOLOv11 多目标检测 → 自动估算重量和营养成分 |
| ✍️ **手动录入** | 下拉菜单选择食物，手动输入重量，无需照片 |
| 📊 **今日概览** | 环形进度图展示热量/蛋白质/碳水/脂肪完成度 |
| 📋 **膳食记录** | 按日期查询、删除记录，导出带格式 Excel 报告 |
| 📈 **周趋势分析** | 四维度柱状图（热量/蛋白质/碳水/脂肪）7 天趋势 |
| 👤 **个人档案** | 身高/体重/年龄/活动量/健康目标 → 个性化每日推荐摄入量 |
| 💬 **AI 营养咨询** | 本地 Ollama 大模型，三甲医院营养科主任医师人设，流式对话 |
| 🔐 **多用户系统** | 注册/登录、密码加密（SHA-256 + 盐值）、数据完全隔离 |

## 🚀 快速启动

### 环境要求

- Python 3.10+
- CUDA（可选，GPU 推理加速）
- [Ollama](https://ollama.com) 已安装并拉取模型

### 安装依赖

```bash
pip install gradio torch ultralytics pandas matplotlib openpyxl ollama pillow numpy
pip install ollama
ollama pull qwen2.5:7b
```

### 配置模型路径

编辑 `foodManager.py` 中的 `MODEL_PATH` 变量，指向你的 YOLO 模型权重文件：

```python
MODEL_PATH = r"model\best.pt"
```

### 启动应用

```bash
python foodManager.py
```

浏览器自动打开 → 注册账号 → 登录 → 开始使用。

## 🔐 多用户系统

- **注册**：用户名 + 密码（≥6位），SHA-256 + 随机盐 + 1000 轮哈希加密
- **数据隔离**：每个用户独立的 `user_data/{username}/` 子目录
- **会话管理**：Gradio State 管理登录状态，登录/主界面区块切换
- **旧数据兼容**：首次启动自动备份旧的单用户数据到 `_old_backup/`

## 💬 AI 聊天功能

- **流式对话**：实时显示 AI 回复，支持多轮上下文记忆
- **会话管理**：新建/切换/删除聊天会话，JSON 持久化
- **动态头像**：根据用户性别自动切换头像（男 `boy.jpg` / 女 `girl.jpg`），修改档案后实时生效
- **营养医师人设**：基于用户档案和当日饮食记录提供个性化建议
- **侧边栏**：历史会话列表，一键切换

## 🎨 界面预览

- **配色**：翠绿色（Emerald #059669）医疗健康风格
- **布局**：标签页导航 + 登录卡片 + 聊天双栏布局
- **头像**：用户头像按性别动态切换，医生头像固定；图片缺失时自动降级

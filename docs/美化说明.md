# 前端美化说明文档

## 设计思路

本次改版在**功能零改动**前提下，为"膳康管家"确立现代医疗健康风设计语言：延续品牌翠绿主色（Emerald #059669→#10b981 渐变），搭配 Slate 中性色系与柔和的页面氛围渐变背景，通过统一的圆角（10/16px）、三级阴影体系和清晰的字体层级提升整体质感。

## 主要布局调整

- **登录/注册页**：整合为单张居中玻璃质感卡片，新增渐变 Logo 徽章；空提示框自动隐藏，消除顶部空洞占位。
- **顶栏**：用户信息改为"头像圆标 + 用户名 + 在线状态点"胶囊徽章，退出按钮改为红色描边胶囊，二者风格统一。
- **导航**：标签页升级为胶囊式（激活态渐变填充），切换带淡入动画。
- **表单**：去除全局 label 绿色胶囊噪音，改为精致小标题；输入框聚焦带品牌色光环；Radio 改为胶囊选项。
- **分组**：膳食记录页的删除操作区、周趋势区及 AI 查房小结区包裹为白色分组卡片，信息层级一目了然。

## 交互增强

主按钮悬停上浮 + 品牌色投影、按下微缩反馈、表格行悬停高亮、面板进入动画、细滚动条等微交互贯穿全局。

## 特殊处理

针对 Gradio 6.12 的 DOM 特性（`elem_classes` 直接作用于组件根元素、单行文本框渲染为 `textarea`）定制选择器；通过 `:has(:placeholder-shown)` 实现纯 CSS 空态隐藏。经自动化回归验证，登录、概览、查询、导出、会话切换、新建聊天、退出等 8 项核心功能全部正常。

---

*改动范围：仅 `health_theme`、`custom_css`、两处纯 HTML 装饰函数及 UI 装饰类；所有组件 `name/id/value`、事件绑定、后端逻辑均未触碰。*

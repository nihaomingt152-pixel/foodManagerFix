## 二、详细修改方案

### 修改1：营养计算逻辑修正（🔴 高优先级）

**当前问题：**
`predict_food()` 函数（第436-438行）将检测到的每种食物每100g营养值直接求和，完全没有考虑单份食物的实际重量。例如检测到"苹果×1 + 香蕉×1"，系统认为摄入的是"苹果100g + 香蕉100g"的营养，但实际一个苹果约200g、一根香蕉约120g。

**修改方案：**

1. **新增 `DEFAULT_PORTION_WEIGHT` 字典**，为每类食物预设默认单份重量（单位：克）：
   - 水果类：苹果200g、香蕉120g、橙子180g、葡萄150g、菠萝250g、西瓜500g
   - 主食类：米饭150g、炒饭250g、炒面250g、炒米粉200g
   - 菜肴类：红烧肉200g、番茄炒蛋200g、宫保鸡丁200g 等（中餐一盘约150-250g）
   - 小吃类：煎饺150g（约8-10个）、炸鸡腿100g、卤蛋50g 等

2. **修改 `predict_food()` 函数**：
   - 不再直接累加每100g营养值
   - 改为：每种食物的营养贡献 = NUTRITION_DB值 × (默认份量 / 100) × 检测数量
   - 总重量的估算值自动计算并回填到 weight_input

3. **修改 `main_predict()` 函数**：
   - 将系统估算的总重量显示给用户
   - 用户可以选择覆盖输入实际称重
   - 营养计算基于用户输入的重量（有秤）或系统估算（无秤）

4. **UI 调整**：
   - 识别结果中增加"系统估算总重：XXXg"的显示
   - 如果用户未手动改重量，使用估算值；否则以用户输入为准

**涉及文件/代码位置：**
- 新增 `DEFAULT_PORTION_WEIGHT` 字典 → `善康管家.py` 第132行之后
- 修改 `predict_food()` → 第409-445行
- 修改 `main_predict()` → 第447-473行

### 修改3：全局单例线程安全（🔴 高优先级）

**当前问题：**
`diet_manager = DietManager()` 是模块级全局变量，Gradio 默认多线程处理请求时，多个用户同时操作可能导致 JSON 文件读写冲突。

**修改方案：**

1. **引入文件锁机制**：
   - 在 `DietManager._load_records()` 和 `_save_records()` 中使用 `threading.Lock`
   - 读和写使用同一把锁，防止读写竞争

2. **具体实现**：
```python
import threading

class DietManager:
    _lock = threading.Lock()
    
    def _load_records(self):
        with self._lock:
            if os.path.exists(RECORDS_FILE):
                with open(RECORDS_FILE, 'r', encoding='utf-8') as f:
                    return json.load(f)
            return []
    
    def _save_records(self):
        with self._lock:
            with open(RECORDS_FILE, 'w', encoding='utf-8') as f:
                json.dump(self.records, f, ensure_ascii=False, indent=2)
```

3. 同样处理 `_load_profile()` 和 `_save_profile()`

**涉及文件/代码位置：**
- `善康管家.py`：`DietManager` 类，第140-192行

### 修改6：按餐次维度拆分统计（🟡 中优先级）

**当前问题：**
`get_daily_stats()` 和 `_generate_report()` 只做全天的总量统计，无法告诉用户"早餐吃了多少、午餐吃了多少"。

**修改方案：**

1. **修改 `_generate_report()` 方法**：
   - 在报告开头增加按餐次分组的小计表格
   - 格式示例：
   ```
   📅 2026-07-20 膳食营养统计报告
   ==================================================
   📋 各餐次摄入概况：
     早餐：350 kcal | 蛋白质 18g | 碳水 45g | 脂肪 12g
     午餐：680 kcal | 蛋白质 35g | 碳水 80g | 脂肪 22g
     晚餐：520 kcal | 蛋白质 28g | 碳水 60g | 脂肪 18g
     加餐：120 kcal | 蛋白质 5g  | 碳水 15g | 脂肪 4g
   ==================================================
   🍚 全天总计：...
   ```

2. **实现逻辑**：
```python
def _generate_report(self, date, intake, recommend, daily_records):
    report = f"📅 {date} 膳食营养统计报告\n"
    report += "=" * 50 + "\n"
    
    # 新增：按餐次汇总
    meal_groups = {"早餐": [], "午餐": [], "晚餐": [], "加餐": []}
    for r in daily_records:
        meal_groups.get(r.get("餐次", "午餐"), []).append(r)
    
    report += "📋 各餐次摄入概况：\n"
    for meal, records in meal_groups.items():
        if records:
            meal_cal = sum(r["热量(kcal)"] for r in records)
            meal_protein = sum(r["蛋白质(g)"] for r in records)
            meal_carbs = sum(r["碳水(g)"] for r in records)
            meal_fat = sum(r["脂肪(g)"] for r in records)
            report += f"  {meal}：{meal_cal:.0f} kcal | 蛋白质 {meal_protein:.0f}g | 碳水 {meal_carbs:.0f}g | 脂肪 {meal_fat:.0f}g\n"
    report += "=" * 50 + "\n"
    # ... 后续全天统计保持不变 ...
```
